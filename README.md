# 🌿Physiotherapy and Rehabilitation Website

A responsive informational website introducing the field of Physiotherapy and Rehabilitation.

## 📌About the Project

This project was created to provide general information about Physiotherapy and Rehabilitation. It introduces the department, its educational content, professional working areas, and frequently asked questions.

## 📄Pages

- **Home:** Introduction to Physiotherapy and Rehabilitation.
- **Education:** Information about the department's educational content.
- **Working Areas:** Overview of different fields of physiotherapy.
- **FAQ:** Answers to frequently asked questions.

## 🛠️Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨Features

- Responsive design for desktop and mobile devices.
- Mobile navigation menu.
- Interactive FAQ accordion.
- Automatic current year in the footer.
